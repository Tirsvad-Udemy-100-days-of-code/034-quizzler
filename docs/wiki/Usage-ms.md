# Penggunaan

> Nota: terjemahan Bahasa Melayu ini belum disemak oleh penutur asli; bahasa Inggeris ialah teks rasmi.

## Jalankan

Dengan `.venv` aktif:

```bash
python -m quizzler
```

Sambungan internet diperlukan untuk mengambil sepuluh soalan benar/palsu.

## Cara bermain

Baca soalan dan tekan tanda semak hijau (Benar) atau pangkah merah (Palsu). Kotak soalan menjadi hijau untuk jawapan betul dan merah untuk jawapan salah, skor di kanan atas bertambah, dan soalan seterusnya muncul selepas satu saat. Selepas soalan terakhir, butang dilumpuhkan dan skor akhir dipaparkan.

## Apabila sesuatu tidak berjaya

Jika perkhidmatan soalan tidak dapat dicapai, tetingkap dengan mesej ringkas dipaparkan dan program tamat dengan kod keluar 1. Semak sambungan internet anda dan cuba lagi.
