# Sumbangan

> Nota: terjemahan Bahasa Melayu ini belum disemak oleh penutur asli; bahasa Inggeris ialah teks rasmi.

Repositori ini menggunakan rangka kerja SQA dan QC dalam `framework/`.

1. Tiada apa-apa diletakkan di bawah `src/` atau `tests/` sebelum pencapaian (milestone) yang mengandungi tugas itu diterima dengan semakan `Go` (`docs/milestones/`).
2. Bekerja pada satu cabang bagi setiap pencapaian, satu pull request bagi setiap pencapaian, dan tutup isu yang disiapkannya dengan satu baris `Closes #N` setiap satu.
3. Semak kod berdasarkan senarai semak Python (`QC-PY-001`) dan rekodkan dalam `docs/sqa/reviews/`.
4. Orang selain pengarang menggabungkan pull request.

Peraturan untuk ejen AI terdapat dalam `AGENTS.md`.
